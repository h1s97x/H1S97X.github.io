## 题目

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `k`。

如果子数组中所有元素都相等，则认为子数组是一个**等值子数组**。

从 `nums` 中删除最多 `k` 个元素后，返回可能的最长等值子数组的长度。

## 思路

滑动窗口 + 哈希表。维护窗口内每个元素的出现频数，窗口内最多允许删除 k 个元素。

条件：`窗口长度 - 最大频数 <= k`，即窗口内非众数的元素不超过 k 个。

## 复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(n)
